# 蕉宗映像製片所操作手冊

## 第一次試拍

使用短片專用 `Banana_Film_Studio.ipynb`，依序①②③。9B 是編劇與攝影導演，必須下載。這份公開版筆記本匿名下載程式，不需要 GitHub Token。使用自己的 Colab GPU 與 Drive；請勿分享包含素材或執行輸出的筆記本副本。

前端不需歌曲、歌詞或 SRT。先選 15 秒上限、單段 10 秒、自然或高動態、無對白。可使用這個小故事測試：

> 一位快遞員在深夜工作室放下一封信。她正要離開，信封卻自行滑回桌面中央。她停下腳步，回頭盯著信封。信封靜止，她伸手又縮回，最後坐下來與它對看。荒謬喜劇、真實表演，不要台詞，結尾留一個停頓。

不提供圖片時由模型設計外觀；需要同一角色時，上傳圖片並用 `@圖片1` 指定。圖片只用來維持身分與所指定外觀，表情、眼睛與動作由事件決定。演唱會、重金屬、字幕及配樂都不會因原 MV 底稿自動加入。

## 先產劇本，再決定開拍

題材可複選：搞笑、電影、戲劇、武打、愛情、BL、運動、科幻、懸疑恐怖。「自動導演」勾選時依故事主軸創意發展；取消則依提供的事件與台詞安排拍攝。兩者都維持明確角色與結局要求。

圖片使用九格獨立選取：選第二格不會取代第一格；清空某格不會讓後方圖片補位。例如只選第 3 格，故事仍寫 `@圖片3`。送到模型時內部會映射為已連接素材，前端劇本維持原格號。末幀模式最多八張實際圖片，格號不受影響。

按「生成劇本」只呼叫 9B 安排分場，完成後停在劇本預覽，不排入 H3。可以修改名稱、段落秒數、模式與內容，也可增加／刪除段落，總長仍需符合上限。

在「劇本方向修改意見」填寫要改哪裡，再按「請導演修這版」。導演拿到目前編輯中的劇本、原始設定及本次意見，依意見細修，指令要求保留無關段落。模型是否完全做到仍須看稿。細修前版本保存於專案，可載入舊稿再編輯。失敗時保留原稿，不開拍。手動儲存與載入舊稿也不開拍。

最後按「確認劇本並開拍」才開始下游攝影改寫與 H3 生成。確認後不可再覆寫整份劇本；已生成內容使用毛片補拍功能處理。重新開啟已存作品可繼續檢視尚未開拍的劇本。

更新到這版請使用新的 Colab 執行階段並重跑①②③；僅重新整理前端不會更新舊的後端。Drive 中已保存作品繼續保留。

## 導演與聲音

新建作品開啟自動導演時，所選片長是故事發展目標，同時仍是生成上限。上游須安排有因果的事件、選擇、後果與必要反應；影格對齊後總長通常至少達目標的 70%，若分段上限與原生網格無法達成，使用可行的最長總長作門檻。過短的模型劇本會帶原稿退回上游補寫，重試用盡就停止，不把空白或結局重複填滿時間。此數值驗收不能判斷事件是否真的足夠，仍需審閱劇本。取消自動導演時維持忠實內容與自然長度。舊作品維持原規則；手動儲存、確認開拍及局部細修不強制補長，不擅改使用者編輯的劇本。每段可包含多個鏡頭，分段長度不等於鏡頭長度。時間安排會向下對齊 H3 的原生影音影格網格，避免額外生成較長台詞後再截掉結尾。

「無對白」使用環境音與動作音效，不加入說話或歌唱。「依故事安排對白」允許 9B 擴寫簡短台詞；重要句子請寫明角色、語言及原句。下游只收到這一段的委託，不收到整首故事或未來結局。

H3 同時生成影音，解碼並保留各段的聲音。毛片可直接聽對白與環境音。無人聲並不等於沒有音軌；若模型完全沒輸出音軌，程式會停止，不以無聲片假裝完成。此檢查只確認音軌存在，不驗證對白正確或聲音好聽。

跨段聲線與音樂尚未鎖定，不保證配樂平滑相接。故事若指定同一聲線，9B 應將所需聲音描述帶入當段委託，但模型實際服從程度仍需驗片。

## 劇情短片導演

上游在既有 brief 中自然交代每段戲劇目的：局勢、人物關係或觀眾理解如何改變。台詞、行動、聆聽反應與必要停頓共同分配秒數；必留原句不為塞進單段而刪除，應在總長上限內重新安排段落。

跨段規劃須對照位置、視線、手持物、已完成動作與情緒。下游仍只接收當段委託，將其轉成場面調度、表演與攝影，不讀後續結局。不固定鏡頭數或切鏡間隔，不把電影感等同慢拍；喜劇、愛情、武打與情緒戲依當下事件決定節奏。

上述為導演指令，並非已實現的自動視覺驗收或精確剪輯時間軸。原生音訊與合成流程維持原樣；未加入配音替換、音畫錯位剪接或外部生成服務。

## 補拍與續拍

「毛片放映室」列出完成片段與各次版本。填局部修改建議、勾選片段再重拍；留空則只換 Seed。9B 只改這段，沒有重排全片。整批成功後才採用並合成新版，原毛片與完整成片保留。

預覽舊版不代表採用；要以它繼續補拍，先按「採用此版」。原生音軌跟著採用的毛片一起更換。補拍可能產生不同聲線，請同時聽接點。

「本段完成後停機」會在目前工作完成後停止；若正在規劃，等該次 9B 呼叫返回。中斷後開啟已存作品按「繼續製作」，沿用完成片段及已存攝影稿。下游改寫失敗可續拍；要換全片故事或上限，請建立新作品。

增加前段末幀模式只是參考連續性；同批相鄰補拍會使用新末幀，未選的後段不自動重拍，請檢查動作與場景接點。

## 完整作品

儲存 Drive 時：

```text
MyDrive/BananaFilmStudio/films/工作編號/final.mp4
MyDrive/BananaFilmStudio/films/工作編號/final_v001.mp4
MyDrive/BananaFilmStudio/films/工作編號/final_v002.mp4
```

前端可分別下載版本。`final.mp4` 是目前採用的完整作品；`videos` 只是額外副本。模型安裝與 ComfyUI 可沿用相同權重，但不要同時執行其他 MV 任務。

關閉網頁或 ComfyUI 不等於釋放 GPU；結束後請在 Colab 中斷並刪除執行階段。這份初版已做離線流程測試，實際 GPU 品質與手機排版仍待試拍。


## 直接開拍

表單保留「生成劇本」：9B 規劃後停下，可手改、細修、確認開拍。新增「直接開拍」：使用同樣的故事規劃、AUTO 目標時長與 70% 過短驗收，成功後直接進入逐段攝影改寫及 H3 生成，不停在劇本審閱。這條路徑不新增模型或另一套規劃器，僅使用既有 script_review=false。兩個按鈕共用素材、設定與防重複提交；直接開拍進行中不能覆寫全片劇本。


## 參考圖與長篇輸入

先在上方九格選參考圖，再填故事。輸入 `@` 會顯示已選圖片的縮圖選單；可點選，或用上下方向鍵與 Enter 選擇。空格不遞補編號，中文輸入法組字期間不攔截 Enter。

故事上限為 30,000 字元，前後端皆驗證；文字框會顯示字數。超限內容仍可貼上與編輯，但需刪減後才能送出，不會默默截短。這是應用程式輸入限制，不是模型 token 或顯存安全上限。9B 輸出仍維持 8192 tokens。

參考圖依實際內容辨識 PNG/JPEG/WebP，下載後沒有副檔名的圖片也可使用。這個短片入口不接受音訊作為參考圖；聲音由 H3 生成。
