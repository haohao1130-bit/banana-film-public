# 🎬 大乘蕉宗・映像製片所

公開測試版短片製作工作室。輸入故事、選填角色／場景參考圖，交給本地 9B 規劃，再由 MiniMax H3 逐段生成原生影音。作品上限三分鐘；自動導演以所選時間發展故事，最低門檻為目標的 85%，取消自動導演則依原內容自然收尾。

[在 Colab 開啟短片製作所](https://colab.research.google.com/github/haohao1130-bit/banana-film-public/blob/main/Banana_Film_Studio.ipynb)

**初版尚待 GPU 實測。先以 15 秒上限、無對白模式試拍。** 離線測試驗證程式接線與媒體處理，不能證明 9B 的實際劇情／攝影品質或 H3 聲音品質。

## 如何開始

1. 開啟 `Banana_Film_Studio.ipynb`，使用 G4 或 A100 GPU。
2. 程式匿名下載，不需要 GitHub Token。模型如需驗證，可在 Colab 左側密鑰設定唯讀 `HF_TOKEN`。每位使用者使用自己的 Colab GPU，GPU 費用由自己的帳號負擔。
3. 執行①安裝、②模型、③啟動，打開「蕉宗映像製片所」。
4. 填故事、選填參考圖，九格各自選圖，用 `@圖片1` 等固定格號指定用途。題材可複選，自動導演可勾選。選全片上限、單段上限、風格及原生聲音模式，按「生成劇本」。先預覽、手動編輯或填意見按「請導演修這版」，最後「確認劇本並開拍」；也可按「直接開拍」，讓規劃完成後立即生成影片。
5. 在毛片放映室聽聲音、看畫面。勾選片段補拍；局部修改留空只換 Seed，填寫則由 9B 修當段稿。完整成片各版本保留。

無參考圖也能開拍；H3 依文字生成外觀，跨段身分穩定性較無保障。原圖參考最多 9 張；增加前段末幀作連續性參考時最多 8 張。

## 與 MV 的差別

| 項目 | 短片入口 |
| --- | --- |
| 輸入 | 故事＋選填參考圖，不需要歌曲或 SRT |
| 時間 | 9B 在 6–180 秒上限內選擇實際長度；每段依 H3 影格網格安排 |
| 上游 | 一次規劃全片，每段帶當前人物、空間、事件、情緒、聲音與局部結束狀態 |
| 下游 | 只拿當段委託設計電影攝影、表演與剪輯，不看完整故事／未來結局 |
| 生成 | 原生 `MiniMaxH3ReferenceToVideo`，聯合音畫 latent 分別解碼；無 `lock_source` |
| 聲音 | 保留 H3 生成的對白與環境音，合成時不換成外部歌曲 |
| 前端 | 獨立放映機視覺、分場、大綱、提示詞、毛片、補拍與完整版本 |
| 連續性 | 可加入上一段末幀作參考，不硬鎖下一段首幀，不繼承動作 latent |

無對白模式禁止人聲／台詞。有對白模式讓導演依故事分配簡短台詞；重要台詞請明寫說話角色與原句。沒有明確要求時不自動配背景歌曲。

## 已知限制與驗證

H3 逐段生成的聲線、口音、配樂與環境音可能跳接；參考圖維持身分但不保證所有片段完全相同。沒有新增配音鎖聲線或全片背景音樂後製。片長上限不是精確逐格剪輯命令，實際長度會依 H3 合法影格網格略縮短。

測試涵蓋原生影音圖接線、無歌曲建立作品、一次規劃與當段隔離、續跑、補拍，以及真實 FFmpeg 音軌保留。已有 DOM／HTTP mock 前端功能測試。9B／H3 GPU 生成、Colab 啟動與手機實際操作仍需試拍驗證。

詳細操作見 [短片手冊](docs/film_studio.md)，第三方來源與權重授權見 [來源與致謝](THIRD_PARTY.md)。自有程式採 MIT 授權，第三方元件與模型依各自條款。
```bash
python -m unittest discover -s tests
node tests/check_film_ui.cjs
```

回爐／重拍使用同目錄分段版本檔（例如 `00_raw_v2.mp4`、`00_part_v2.mp4`），先預覽、選好各段版本，再確認凝丹／合成。重拍不自動替換成片。詳見 [版本與回爐說明](docs/clip_review.md)。


## 末五幀動作接續

「跨段連續性」新增可選的末五幀動作接續（實驗），以原生動作引導接入前段最後五幀，影音裁除重疊後維持計畫片長。角色圖片編號不變，最多九張圖；預設仍為單張末幀參考。補拍接續與媒體裁除已做離線測試，實際動作接縫與跨段聲線仍需試拍驗收。更新請使用新的 Colab 執行階段重跑①②③，僅刷新前端不會更新程式。

預設使用動態分段（每段最長 15 秒），保留手選 6／10／15 秒上限；中間段與全片結尾分開交代，避免每段自行收尾。適用各種題材，內容與接縫仍需審稿及試拍。
